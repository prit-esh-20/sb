
| Memory Address | Assembly Code         | Comments                                   |
| -------------- | --------------------- | ------------------------------------------ |
| 0000H          | ORG 00H               | Set program starting address               |
| 0000H          | AGAIN: MOV TMOD, #10H | Configure Timer 1 in Mode 1 (16-bit timer) |
| 0003H          | MOV TH1, #0DBH        | Load higher byte of timer count            |
| 0006H          | MOV TL1, #0FFH        | Load lower byte of timer count             |
| 0009H          | SETB TR1              | Start Timer 1                              |
| 000BH          | BACK: JNB TF1, BACK   | Wait until Timer 1 overflow flag is set    |
| 000EH          | CLR TR1               | Stop Timer 1                               |
| 0010H          | CPL P1.3              | Complement (toggle) pin P1.3               |
| 0012H          | CLR TF1               | Clear Timer 1 overflow flag                |
| 0014H          | SJMP AGAIN            | Repeat the process continuously            |
| 0016H          | END                   | End of source program                      |

ALGORITHM:
1. Initialize Timer 1 in Mode 1 using the TMOD register.
2. Load TH1 with DBH and TL1 with FFH to set the timer count.
3. Start Timer 1 by setting the TR1 bit.
4. Check the TF1 flag and wait until it becomes 1.
5. Stop Timer 1 by clearing the TR1 bit.
6. Complement pin P1.3 to toggle its output state.
7. Clear the TF1 overflow flag.
8. Repeat the process continuously by jumping to AGAIN.

Delay Calculation:

10 ms = (Max count - Count) × Time for 1 machine cycle

       = (FFFFH - Count) × 11.0592 / 12

10 ms = (65536 - Count) × 11.0592 / 12

∴ Count = DBFFH

TH1 = 0DBH, TL1 = 0FFH
